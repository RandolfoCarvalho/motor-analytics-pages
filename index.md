# motor-analytics

Ferramenta pessoal de análise de desempenho de canais do YouTube, de uso exclusivo do próprio dono dos canais. Não é um serviço público.

## Política de Privacidade

O motor-analytics acessa, com autorização do proprietário e somente para leitura, dados de análise dos canais do YouTube dele (visualizações, impressões, origens de tráfego, retenção e curtidas) por meio da YouTube Analytics API e da YouTube Data API.

Os dados são armazenados apenas localmente, no computador do proprietário. Nenhum dado é vendido, compartilhado, divulgado ou transferido a terceiros. O app não publica, edita nem exclui conteúdo.

O uso das informações obtidas das APIs do Google segue a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

A autorização pode ser revogada a qualquer momento em https://myaccount.google.com/permissions

Este app é de uso pessoal do proprietário e é fornecido sem garantias. Não há contas de usuários nem coleta de dados de terceiros.
